# @deepseek-ai/dsh-experimental-browser-use-runtime

日本語 | [English](README.en.md) | [中文](README.zh.md)

## 概要

ブラウザープロバイダーはこのライブラリを使い、1 セッションのターン間でブラウザーを再利用し、そのセッションのランタイム破棄時にリソースを閉じる。1 セッションの操作は順序どおりに実行され、分離されたセッションは独立に進行できる。添付モードは 1 件の外部ブラウザーを単一セッションに予約する。このライブラリはプロバイダー所有 MCP サーバーも接続し、セッション最初のモデルリクエストの前にそのツールを検出する。

<a id="use-this-package"></a>
## このパッケージを使う

この公開実験ライブラリはブラウザープロバイダーの依存関係である。プラグイン入口やマウント設定はない。[browser-use サービス](../../browser-use/browser-use/README.md)はライブラリから独立したままである。

ネイティブプロバイダーはパッケージルートから `SessionResources` を構築し、リソース取得とクリーンアップコールバックを提供する。呼び出しは正確なライブエージェントを `run()` に渡す。古い所有者と排他添付の第 2 所有者は取得前に失敗する。取得待ちのキャンセルは同セッションの他呼び出しに初期化を利用可能に残し、セッション破棄はその初期化を中断して待つ。プロバイダーは `dispose()` 完了まで登録を保持する。

MCP プロバイダーは `@deepseek-ai/dsh-experimental-browser-use-runtime/mcp` から `mountSessionMcp` を使い、固定サーバー名・実行可能ファイル・引数・所有権ポリシーを提供する。マウントコンテキストは `workingDirectory` を提供しなければならない。取得は[作業ディレクトリサービス](../../session/working-directory/README.md)を使い現行ディレクトリを検証または回復し、MCP サーバープロセスの初期ディレクトリを設定する。保持サーバーはセッションが後に他ディレクトリを選んでもそのディレクトリを保持する。ヘルパーは将来エージェントごとの `agent/created` イベント内でスコープ付きクライアント起動と検出試行を 1 件待つ。エージェント作成または再開は検出後、キュー済み入力実行前に完了し、成功クライアントはターン越えでそのセッション所有のまま残る。

多忙な添付はそのライブ有効化に対する起動を恒久的に省き、他の作業は続ける。添付の解放は省いた有効化を再試行しない。新規作成または再開エージェントはそれを取得できる。起動失敗またはキャンセルはエージェント作成または再開を拒否し、クライアントクリーンアップを含む作成ロールバックを起こす。再接続は無効である。プロバイダーの読み込みや再読み込みは将来のエージェント有効化にのみ適用される。

呼び出し側は待機済みエージェント作成または再開の完了後にプロンプト組み立てとスコープ付きツール定義を検査できる。

このサーバーを対象とするブラウザーツールとリソース要求は同一キューを使い、呼び出しセッション自身の接続を要求する。他 MCP サーバーは利用可能なままである。継承サーバー指示は所有権なしで省略され、共有サーバー名目録は通常スコープ動作を保つ。

<a id="understand-the-implementation"></a>
## 実装を理解する

<details>
<summary>実装内部 — クリックして展開</summary>

[リソース管理器](src/index.ts)は所有権をライブエージェント同一性でキー付けし、操作キャンセルと所有者破棄を結合する。各リソースは取得プロミス 1 件と操作キュー 1 件を持つ。取得失敗はプロバイダーコールバックが取得済みリソースをロールバックした後にのみ予約を解放する。

破棄起因キャンセルは AgentHandle が idle を待つ前にリソースクリーンアップを開始する。クリーンアップは実行中操作を待つ前にリソースを閉じ、接続破棄が中断対応のない上流 API を中断できるようにする。失敗した close は破棄を拒否し、所有権を保持する。エージェントスコープのクリーンアップは同一耐久 id の再開セッションが以前のブラウザーを継承しないようにする。

[MCP ヘルパー](src/mcp.ts)は直列 `agent/created` 内で接続する。[AgentLoop](../../core/agent-loop/README.md#understand-the-implementation)はキュー済み入力を保持し、作成ロールバックを所有する。プロンプト組み立ては初期化済みカタログを読む。ヘルパーはリソースクリーンアップを通じてプロバイダー登録を保持し、転送・スキーマ検出・結果変換・耐久画像承認に [MCP クライアント](../../mcp/mcp-client/README.md) を使う。

</details>

<a id="model-experience"></a>
## モデル体験

間接的に、モデルリクエスト組み立て前に検出されるプロバイダー所有ブラウザーツールと[作業ディレクトリ回復](../../session/working-directory/README.md)を通じて。プロバイダーと MCP クライアントがツール説明・スキーマ・結果・画像動作を所有し、ディレクトリサービスがディレクトリ文脈を所有する。

#### KV キャッシュ効果

検出ツールスキーマとプロバイダー指針がリクエストプレフィックス変更を決める。通常のブラウザーリソース再利用はそれらスキーマを変更しない。ディレクトリ回復はシステムプロンプトプレフィックスを置換せずにユーザー文脈を追記する。

## 既知の制限と deferred work

<a id="known-limitations-and-deferred-work"></a>

ブラウザー操作の責任はプロバイダーに残る。

- **MCP 有効化** — プロバイダーは既存ライブエージェントを採用しない。多忙な添付はその有効化内で再試行されない。
- **添付スコープ** — 排他所有権は 1 件のリソース管理器に適用され、別プロバイダー・プロセス・外部ブラウザークライアントには適用されない。
- **キャンセル** — 中止シグナルと接続終了は既に配送されたブラウザー操作を取り消せない。両方を無視する上流操作はクリーンアップを遅延させ得る。
- **回復** — 失敗した close は所有権を保持する。この管理器は破棄を再試行せず、セッションログからブラウザー状態を復元しない。
- **共有ホストランタイム** — プロファイルは dsh インストールのそばにこのパッケージを置くため、`@deepseek-ai/dsh-scope` と `@deepseek-ai/dsh-mcp-client` はピア依存のままである。依存辺は第 2 の `dsh-scope` 複製を出荷し、そのスコープタグをホストレジストリは読めない。各エージェントの MCP ツールはグローバルツール層に登録され、第 2 エージェントの作成は失敗する。
