# @deepseek-ai/node-addon-system-darwin-arm64

日本語 | [English](README.en.md) | [中文](README.zh.md)

このプラットフォームパッケージは `bin/system.node` を供給する。これは `@deepseek-ai/node-addon-system/flock` が使う安定した Node-API v8 アドオンである。Landlock 実行ファイル、JavaScript ローダー、インストール時のビルドスクリプトは含まない。ネイティブワークフローが macOS arm64 でこれをビルドし、そのインストール済みアーティファクトの検証を所有する。
